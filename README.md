# Мир кавалеров

## О проекте

«Мир кавалеров» — информационный блог, посвящённый породе собак кавалер-кинг-чарльз-спаниель.

На сайте представлены материалы об особенностях породы, характере собак, уходе и содержании.

## Практические работы

**Практическая работа № 1**
- Создание проекта на Django.
- Настройка виртуального окружения.
- Установка необходимых зависимостей.
- Настройка и запуск Django-сервера.

**Практическая работа № 2**
- Создание структуры приложения для блога.
- Настройка URL-адресов и функций-обработчиков.
- Создание HTML-шаблонов с наследованием.
- Подключение CSS и изображений.

**Практическая работа № 3**
- Создание модели для хранения отзывов.
- Регистрация модели в административной панели Django.
- Создание формы для отправки отзывов.
- Настройка проверки и публикации отзывов администратором.

## Установка проекта

1. Склонировать репозиторий:

   `git clone https://github.com/Natashshasha/first-django.git`

2. Перейти в папку проекта:

   `cd first-django`

3. Создать виртуальное окружение:

   `python -m venv .venv`

4. Активировать виртуальное окружение:

   `.venv\Scripts\activate`

5. Установить необходимые библиотеки:

   `pip install -r requirements.txt`

## Запуск первой практической работы

Перейти в папку:

`cd practice1`

Запустить сервер:

`python manage.py runserver`

## Запуск второй и третьей практических работ

Перейти в папку:

`cd urlsite`

Выполнить миграции:

`python manage.py migrate`

Запустить сервер:

`python manage.py runserver`

После запуска открыть в браузере:

- Главная страница блога: http://127.0.0.1:8000/
- Книга отзывов: http://127.0.0.1:8000/reviews/
- Административная панель: http://127.0.0.1:8000/admin/

Для входа в административную панель необходимо создать администратора командой:

`python manage.py createsuperuser`

Новые отзывы отображаются на сайте только после проверки и публикации администратором.
